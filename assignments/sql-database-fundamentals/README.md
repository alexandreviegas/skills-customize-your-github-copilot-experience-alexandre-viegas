# 📘 Assignment: Database Fundamentals with SQL

## 🎯 Objective

Learn how to design a simple database, write SQL queries, and manage records using a relational structure that supports real-world data.

## 📝 Tasks

### 🛠️ Design the database schema

#### Description

Create a small database structure for a real-world scenario, such as students, courses, books, or orders.

#### Requirements

The completed database must:

- Define at least two related tables.
- Include primary keys and meaningful column names.
- Use appropriate data types for text, numbers, and dates.
- Add at least one foreign key relationship between tables.

### 🛠️ Insert sample data

#### Description

Populate the tables with realistic sample records so the database can be queried meaningfully.

#### Requirements

The completed database must:

- Insert multiple rows into each table.
- Include enough data to demonstrate relationships between records.
- Ensure each record has valid values and no missing required fields.
- Use SQL `INSERT` statements to add the data.

### 🛠️ Query and analyze the data

#### Description

Write SQL queries to retrieve useful information from the database.

#### Requirements

The completed database must:

- Use `SELECT` statements to display all records from a table.
- Filter results with a `WHERE` clause.
- Sort records using `ORDER BY`.
- Join at least two tables using `INNER JOIN`.
- Use aggregate functions such as `COUNT`, `SUM`, or `AVG` when appropriate.

### 🛠️ Practice data updates and cleanup

#### Description

Modify and review records to practice basic database maintenance.

#### Requirements

The completed database must:

- Update at least one record using `UPDATE`.
- Delete at least one record using `DELETE`.
- Explain how the changes affect the related data.
- Share a short summary describing the goal of the database and the value of the queries used.
