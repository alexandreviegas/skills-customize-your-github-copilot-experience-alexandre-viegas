# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Crie um jogo da forca em Python para praticar manipulação de strings, laços de repetição, condicionais e entrada de dados do usuário.

## 📝 Tarefas

### 🛠️ Criação da Lógica do Jogo

#### Descrição

Desenvolva um jogo de adivinhação de palavras em que o jogador tenta descobrir uma palavra oculta antes de esgotar as tentativas.

#### Requisitos

O programa concluído deve:

- Selecionar uma palavra aleatória a partir de uma lista predefinida
- Exibir a palavra oculta com underscores e atualizá-la conforme as letras forem acertadas
- Receber a entrada do jogador em cada tentativa
- Controlar o número de erros e as tentativas restantes
- Encerrar o jogo quando a palavra for adivinhada ou quando as tentativas acabarem
- Exibir uma mensagem clara de vitória ou derrota

### 🛠️ Melhoria da Experiência do Jogador

#### Descrição

Adicione feedbacks e interações que facilitem o acompanhamento do jogo e tornem a experiência mais agradável.

#### Requisitos

O programa concluído deve:

- Mostrar as letras já utilizadas pelo jogador durante a partida
- Exibir o estado atual da palavra após cada tentativa
- Tratar entradas inválidas, como letras repetidas ou caracteres que não sejam letras
- Permitir reiniciar o jogo após o fim da partida
