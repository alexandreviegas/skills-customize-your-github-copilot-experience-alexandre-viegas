# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a classic hangman game in Python to practice string manipulation, loops, conditionals, and user input.

## 📝 Tasks

### 🛠️ Create the Game Logic

#### Descrição

Develop a word-guessing game where the player tries to discover a hidden word before running out of attempts.

#### Requisitos

O programa concluído deve:

- Choose a random word from a predefined list
- Display the hidden word using underscores and update it as letters are guessed
- Accept input from the player for each attempt
- Track the number of incorrect guesses and remaining lives
- End the game when the word is guessed correctly or the attempts are exhausted
- Show a clear message for victory or defeat

### 🛠️ Improve the Player Experience

#### Descrição

Add small interactions and feedback that make the game easier to follow and more engaging for the player.

#### Requisitos

O programa concluído deve:

- Show the letters already used by the player during the game
- Display the current state of the word after each guess
- Handle invalid inputs such as repeated letters or non-letter entries gracefully
- Offer a way to restart the game after it ends
