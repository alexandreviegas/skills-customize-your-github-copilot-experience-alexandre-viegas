# 📘 Assignment: Building Web Applications with OutSystems

## 🎯 Objective

Create a small web application in OutSystems, learning how to design screens, organize data, and implement business logic to build a functional user-facing solution.

## 📝 Tasks

### 🛠️ Design the Application Layout

#### Description

Create a simple web application interface with a clear navigation flow and a page structure that is easy for users to understand.

#### Requirements

The completed application must:

- Create a home screen or landing page.
- Add at least two other screens or sections for different actions, such as list, detail, or form pages.
- Use consistent labels, spacing, and visual hierarchy.
- Ensure the app is easy to navigate and mobile-friendly.

### 🛠️ Build the Data Model

#### Description

Define the information your application needs and organize it using OutSystems entities and relationships.

#### Requirements

The completed application must:

- Create at least one entity to store application data.
- Add fields with appropriate names and data types.
- Define a basic relationship or use a simple record structure when needed.
- Confirm that the app can save and retrieve records from the data model.

### 🛠️ Add User Interaction and Business Logic

#### Description

Implement actions that make the application useful, such as adding, editing, searching, or submitting information.

#### Requirements

The completed application must:

- Include at least one form where users can enter data.
- Add a submit or save action that stores the information.
- Include validation for required fields or invalid values.
- Add at least one business rule, such as conditional display, filtering, or calculated values.

### 🛠️ Publish and Present the Solution

#### Description

Review the app, test the flow, and prepare it to share with others.

#### Requirements

The completed application must:

- Test the main user flow from start to finish.
- Confirm that the app works without major errors.
- Explain briefly how the screens, data model, and logic connect with each other.
- Present the final result in a short demo or walkthrough.
